 Description: Meizu E3 display and touch integration (DKMS)
  Driver and device-tree overlay sources live under /usr/src/meizu-e3-dkms-<ver>/
  (Makefile, drivers/, overlay/). DKMS builds kernel modules on the target at
  configure time; postinst compiles the versioned overlay to
  /boot/dtbo/*.dtbo.disabled
  when dtc is available.
  Touch mapping is deliberately not performed from an X11 autostart helper:
  display probing and layout changes are kept out of the kernel bring-up path.
  .

  linux-headers matching your running kernel (uname -r) from your vendor or
  board image repository (e.g. Radxa) before expecting DKMS or overlay build to
  succeed.
